# ДГИ — Система техподдержки

Внутренняя система техподдержки Департамента городского имущества города Москвы.

## Функционал

- **Заявки** — создание, назначение инженеров, отслеживание статуса, приоритеты, комментарии, вложения
- **Оборудование** — учёт моноблоков, принтеров, расходных материалов с категориями и подкатегориями
- **База знаний** — статьи, инструкции, политики
- **Уведомления** — рассылки администратора, уведомления по заявкам
- **Пользователи** — управление ролями (админ, инженер, пользователь)

## Стек

- **Backend:** FastAPI, SQLAlchemy, MySQL
- **Frontend:** Jinja2, TailwindCSS
- **Deploy:** Docker, Render

## Запуск локально

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -r requirements.txt
python seed_users.py     # заполнить БД тестовыми данными
uvicorn app.main:app --reload
```
